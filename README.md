# مونلی استودیو — سازنده ربات تلگرام Hermes

داشبورد فارسی و راست‌چین برای راه‌اندازی ربات تلگرام روی Cloudflare Workers، به‌همراه پایگاه داده Cloudflare D1 برای نگهداری تاریخچه گفتگوها. ربات درخواست‌ها را به یک endpoint سازگار با OpenAI (`/chat/completions`) می‌فرستد؛ بنابراین می‌توانید از Hermes یا هر ارائه‌دهنده‌ای که همین قرارداد API را دارد استفاده کنید.

## انتشار خود استودیو روی Cloudflare

پیش‌نیاز: Node.js نسخه `22.12` یا جدیدتر، و یک حساب Cloudflare.

```bash
git clone -b arena/104ac7b7-monli https://github.com/hirsad822/MONLI.git
cd MONLI
npm install
npx wrangler login
npm run cf:dev       # اجرای آزمایشی محلی
npm run deploy       # انتشار روی Cloudflare Workers
```

در اولین انتشار، Wrangler حساب را انتخاب می‌کند و Worker با Assets استاتیک منتشر می‌شود. پس از پایان، آدرس `*.workers.dev` را در خروجی می‌دهد؛ همان نشانی داشبورد مونلی است. اگر دامنه `workers.dev` هنوز برای حساب فعال نشده، آن را از بخش Workers & Pages در داشبورد Cloudflare فعال کنید. تنظیمات انتشار در `wrangler.toml` است.

برای به‌روزرسانی نسخه‌ی منتشرشده، در همین پوشه `git pull` و سپس `npm run deploy` را اجرا کنید. روش انتشار از خط فرمان از GitHub Actions/Build به API token ذخیره‌شده در CI نیاز ندارد؛ `wrangler login` احراز هویت را انجام می‌دهد.

## راه‌اندازی ربات از داشبورد

بعد از باز کردن داشبورد منتشرشده، فرم «ساخت ربات» به این موارد نیاز دارد:

1. **Cloudflare API Token** با دسترسی‌های ویرایش Workers و D1 برای حساب هدف.
2. **Cloudflare Account ID**.
3. **توکن Bot تلگرام** که از `@BotFather` می‌گیرید.
4. **کلید API و نشانی HTTPS سرویس Hermes/مدل** که endpoint سازگار با OpenAI داشته باشد.
5. نام مدل مورد استفاده در درخواست‌های chat completions.

با ارسال فرم، سرویس ابتدا توکن‌ها را بررسی می‌کند، سپس D1 و جدول تاریخچه گفتگوها را می‌سازد، Worker را بارگذاری می‌کند، کلیدها را به‌صورت Worker Secret تنظیم می‌کند، دامنه `workers.dev` موجود حساب را فعال می‌کند و webhook ربات تلگرام را ثبت می‌کند. Worker تا ۶ پیام قبلی را برای تداوم گفتگو از D1 می‌خواند، تاریخچه هر گفتگو را به ۲۴ پیام اخیر محدود می‌کند و webhook را با secret token تلگرام اعتبارسنجی می‌کند.

> برای ساخت ربات باید زیردامنه‌ی `workers.dev` حساب Cloudflare فعال باشد. اگر حساب هنوز زیردامنه ندارد، آن را در بخش Workers & Pages فعال کنید و دوباره تلاش کنید. نشانی API مدل باید HTTPS و با قرارداد OpenAI Chat Completions سازگار باشد.

## اجرای محلی با Node.js

```bash
npm start
```

سپس `http://localhost:3000` را باز کنید. برای اجرای نسخه‌ی Cloudflare در محیط محلی نیز `npm run cf:dev` را اجرا کنید. پورت برنامه را با متغیر محیطی `PORT` می‌توان تغییر داد.

## امنیت و محدودیت‌ها

- مقادیر توکن در `localStorage`، کوکی یا فایل تنظیمات ذخیره نمی‌شوند؛ هنگام provisioning به‌طور موقت از مرورگر به سرور فرستاده می‌شوند و پس از موفقیت فیلدهای حساس پاک می‌شوند. فرم از autofill جلوگیری می‌کند.
- کلیدهای Telegram و Hermes در Worker ربات به‌صورت Secret ذخیره می‌شوند، نه در سورس Worker.
- گفتگوهای اخیر تا سقف ۲۴ پیام برای هر شناسه گفتگو در D1 همان ربات ذخیره می‌شوند.
- این مخزن یک استودیوی شخصی است، نه محصول چندکاربره آماده‌ی انتشار عمومی. آن را روی دامنه عمومی بدون احراز هویت و محدودسازی دسترسی قرار ندهید. دسترسی توکن Cloudflare را به حداقل منابع لازم محدود کنید.
- ساخت منابع Cloudflare چندمرحله‌ای است؛ اگر API در میانه‌ی کار خطا بدهد، منابعی که قبلاً ساخته شده‌اند ممکن است باقی بمانند و از داشبورد Cloudflare قابل حذف باشند.
- آمار و نمودار داشبورد فعلاً نمایشی است؛ آمار زنده‌ی مصرف یا گزارش‌گیری در این نسخه به API جداگانه نیاز دارد.
